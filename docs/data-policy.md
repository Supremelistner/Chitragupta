# Data Policy

## What goes where

- **`data/Sample/`** — *real documents you uploaded to test with.*
  Gitignored. Never committed. The repo currently has four real documents
  here: `aadhaar card.jpeg`, `Matriculation Marksheet.jpeg`,
  `Pan Card.jpeg`, `Registration for Vehicle.jpeg`. These may contain real
  Aadhaar numbers, PANs, names, vehicle registration numbers, etc.
  **Do not commit them, ever.** Even on a local branch — once in git
  history, they're recoverable even after `git rm`.

- **`data/Synthetic/`** — *committed.* Generated by
  `scripts/generate_synthetic_docs.py`. All values are obviously fake
  (`9999 8888 7777`, `ABCDE1234F`, `TEST USER SAMPLE`, `TEST 0001`).
  Used by tests and demos.

## Why this split

Real documents (with real PII) are illegal to commit under the Aadhaar Act
2016 (Section 29) and the DPDP Act 2023. Synthetic documents are
deliberately unrealistic so accidental commits cause no harm and the test
data round-trips cleanly through the extraction pipeline.

## Generating synthetic data

```bash
python scripts/generate_synthetic_docs.py
```

Writes four PNGs (`aadhaar.png`, `pan.png`, `marksheet.png`, `vehicle.png`)
to `data/Synthetic/`. Use `--only aadhaar.png` to render a single doc.

## Running tests against real data

For your own ad-hoc testing only, not committed:

```bash
# upload real samples (NOT committed)
curl -X POST -F "file=@data/Sample/aadhaar card.jpeg" \
     http://localhost:8080/documents

# upload synthetic (committed)
curl -X POST -F "file=@data/Synthetic/aadhaar.png" \
     http://localhost:8080/documents
```

## V1 testing policy

All automated tests use `data/Synthetic/`. The real samples in
`data/Sample/` are kept locally for the project owner's manual testing only
and must never enter git.
